### GNS3 
https://gns3.com/software/download

Seleccionaremos el sistema operativo para el cual vamos a descargar la herramienta, en este caso la descargaremos para Mac-Intel
Antes de proceder con la descarga se nos pide que nos creemos una cuenta

https://gns3.com/account/register?redirect=/software/download

Una vez descargada la herramienta como `.dmg` es necesario que movamos la descarga, el archivo `.dmg` a la carpeta de aplicaciones
Cuando lo abramos por primera vez nos preguntará por permisos root, y se los daremos para que podamos ejecutar la aplicacion.

Una vez arrancada la aplicacion, nos aparecerá una ventana **setup wizard** en la que seleccionaremos la opcion *RUN APPLIANCES IN A VIRTUAL MACHINE* -> lo que nos va a permitir correr dispositivos mas modernos de forma mucho más estable

> para ello entonces necesitaremos como requisito tener descargado VirtualBox o VMWare


gns3.com/software/download-vm.
- como estamos haciendo uso de VirtualBox, nos decargaremos la primera opcion para virtualBox
